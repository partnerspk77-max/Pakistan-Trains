# Pakistan Live Train Tracker 🚆

A real-time train tracking and status platform for Pakistan Railways — 
built for commuters, travelers, and anyone tired of outdated schedules.

🔗 **Live Site:** [trains.metro-status.com](https://trains.metro-status.com)

---

## What It Does

- Live train status updates across Pakistan Railways network
- Real-time delay and arrival tracking
- Route and schedule lookup
- Mobile-friendly interface for on-the-go commuters

## Why It Exists

Pakistan Railways serves millions of passengers but reliable, 
real-time train status information has always been hard to access. 
This platform fills that gap — giving commuters accurate, 
up-to-date train information in one place.

## Tech Stack

- **Backend:** Python, FastAPI
- **Frontend:** React, TypeScript
- **Infrastructure:** AWS, Cloudflare
- **Database:** PostgreSQL, Redis
